4. 查詢哪個國家 `總確診` 最多；`GROUP BY` 是用來將資料依照一個或多個欄位進行分組的語句。

    ```sql
    WITH latest_date AS (
        SELECT 國家, MAX(日期) AS 最新日期
        FROM world
        GROUP BY 國家
    )
    SELECT 
        w.國家, w.總確診數 AS 確診總數
    FROM world w
    JOIN latest_date l ON w.國家 = l.國家 AND w.日期 = l.最新日期
    WHERE w.iso_code NOT LIKE 'OWID%'  -- 排除全球與統計用代碼
    ORDER BY 確診總數 DESC
    LIMIT 1;
    ```

_針對前一題的輸出中，查看到不合理數值進行進一步解析_

<br>


3. 可加入篩選條件如 `總確診數 > 1000` 來避免小樣本的異常。

    ```sql
    SELECT 
        國家,
        MAX(總死亡數)::float / NULLIF(MAX(總確診數), 0) AS 死亡率
    FROM world
    WHERE 總確診數 > 1000
    GROUP BY 國家
    ORDER BY 死亡率 DESC
    LIMIT 10;
    ```

    ![](images/img_79.png)

<br>

4. 查看有確診人數但死亡率為空白 `NULL` 或 `0` 的國家；檢視資料中那些 `沒有死亡紀錄` 或 `無確診紀錄` 的異常或特殊情況。

    ```sql
    SELECT 
        國家,
        MAX(總確診數) AS 總確診數,
        MAX(總死亡數) AS 總死亡數,
        MAX(總死亡數)::float / NULLIF(MAX(總確診數), 0) AS 死亡率
    FROM world
    GROUP BY 國家
    HAVING 
        MAX(總死亡數) IS NULL 
        OR MAX(總確診數) IS NULL
        OR MAX(總死亡數)::float / NULLIF(MAX(總確診數), 0) = 0
    ORDER BY 死亡率;
    ```

## 補充說明

_由於資料中包含如 `全球` 等彙總性統計項目，分析時為了保留實際國家的資料，可加入 `WHERE` 條件加以過濾。_

<br>

1. `OWID%` 是 `Our World in Data` 用於表示統計性實體的 `ISO` 代碼前綴，例如 `OWID_WRL` 表示 `全球`、`OWID_CYN` 表示 `北賽普勒斯` 等，這些並不代表實際的國家。

<br>

2. 使用 `NOT LIKE 'OWID%'` 條件排除這些統計項，確保分析結果聚焦於實際國家的資料。

<br>

3. 若資料中同時存在 `ISO 代碼` 與 `國家名稱`，可進一步搭配排除 `國家 = '全球'` 的條件，以避免重複或遺漏。

    ```sql
    WHERE w.iso_code NOT LIKE 'OWID%' AND w.國家 != '全球'
    ```
